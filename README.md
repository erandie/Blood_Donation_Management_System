🩷 FairyCare – Blood Donation & Emergency Response System

FairyCare is a friendly and smart blood donation management system that connects donors, patients, and blood banks in real time. It supports emergency alerts, donor location tracking, and even allows kind hearts to send financial help 💸. Built with love using Spring Boot, FairyCare ensures safe, fast, and meaningful care when it’s needed the most.

✨ Features:

    Find nearby blood donors 🩸

    Emergency alerts via email/SMS 🚨

    Secure donations with PayPal 💖

    Dashboard for managing donors, donations & more 📊

    Cute, clean, and user-friendly UI 🌿

    Because saving lives should be easy, beautiful, and kind 💕
